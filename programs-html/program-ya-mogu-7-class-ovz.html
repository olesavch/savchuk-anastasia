7 Класс • ОВЗ

Рабочая коррекционно-развивающая программа «Я могу»

Программа предназначена для психолого-педагогического сопровождения, эмоционально-волевой регуляции и социальной адаптации учащихся 7 классов с особыми возможностями здоровья (ОВЗ).

Паспорт программы

7 класс ОВЗ (ЗПР 7.2) ФГОС ООО

Адресат: Учащиеся 7 классов с задержкой психического развития (вариант 7.2)

Направление: Коррекционно-развивающая область АООП, психокоррекция

Срок реализации: 1 учебный год (68 часов)
